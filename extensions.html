How Review Works

Community extensions are submitted through pull requests and reviewed before they are listed for public use.

Submit a PR

Add an extension folder under extensions/community/, update marketplace.json, and include docs that explain when to use it.

Automated Checks

CI validates manifest shape, author metadata, duplicate names, referenced files, links, and repository content rules.

Human Review

Reviewers check quality, safety, scope, and whether company-specific rules are labeled separately from public accessibility standards.
